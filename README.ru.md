# Парсер товаров Wildberries

Backend-сервис для парсинга и мониторинга товаров Wildberries.

Приложение получает информацию о товарах по артикулу, сохраняет товары и историю изменения цен в PostgreSQL и автоматически обновляет данные отслеживаемых товаров.

## Возможности

* Парсинг товаров Wildberries по артикулу
* Получение названия, текущей цены и статуса наличия товара
* Сохранение товаров в PostgreSQL
* Ведение истории изменения цен
* Автоматический парсинг товаров, сохранённых в базе данных
* Обработка истёкшей сессии и обновление cookies
* Повторная отправка неудачных запросов
* REST API для управления отслеживаемыми товарами
* Хранение актуальных cookies
* Типобезопасная работа с базой данных через Drizzle ORM

## Стек технологий

* **Bun** — JavaScript runtime
* **TypeScript** — язык программирования
* **Elysia** — HTTP-фреймворк
* **PostgreSQL** — база данных
* **Drizzle ORM** — ORM и управление схемой базы данных
* **Bun.WebView** — получение актуальной браузерной сессии и cookies

## Как это работает

Приложение состоит из нескольких основных компонентов:

```text
                         ┌──────────────────┐
                         │    REST API      │
                         │     Elysia       │
                         └────────┬─────────┘
                                  │
                                  ▼
                         ┌──────────────────┐
                         │     Parser       │
                         │   Wildberries    │
                         └────────┬─────────┘
                                  │
                                  ▼
                         ┌──────────────────┐
                         │   PostgreSQL     │
                         │                  │
                         │    products      │
                         │   priceHistory   │
                         │ cookiesStorage   │
                         └──────────────────┘
                                  ▲
                                  │
                         ┌────────┴─────────┐
                         │  Cookie Manager  │
                         │   Bun.WebView    │
                         └──────────────────┘
```

Парсер отправляет запросы к API Wildberries и извлекает необходимые данные о товаре.

Сервис сохраняет текущее состояние товара в PostgreSQL, а изменения цены записывает в отдельную таблицу истории.

Cookies, необходимые для запросов, сохраняются в базе данных. Если текущая сессия истекает, приложение получает новую через `Bun.WebView`.

## Автоматический мониторинг товаров

Товары, добавленные в базу данных, могут автоматически обрабатываться контроллером.

Контроллер:

1. Получает список товаров из базы данных.
2. Парсит каждый товар.
3. Обновляет его текущее состояние.
4. Записывает изменения цены.
5. Делает задержки между запросами.
6. Повторяет временно неудачные запросы.

Таким образом, сервис может постоянно отслеживать список товаров без необходимости вручную отправлять запрос для каждого товара.

## Работа с сессией и Cookies

Wildberries может вернуть ответ `498`, если текущая сессия больше недействительна.

В этом случае приложение:

```text
Запрос
   │
   ▼
Ответ 498
   │
   ▼
Обновление браузерной сессии
   │
   ▼
Получение новых cookies
   │
   ▼
Сохранение cookies
   │
   ▼
Повторный запрос
```

Для получения новой браузерной сессии и cookies используется `Bun.WebView`.

Актуальные cookies сохраняются в PostgreSQL и используются для последующих запросов.

## База данных

Проект использует PostgreSQL и Drizzle ORM.

### `product`

Хранит текущее состояние отслеживаемых товаров.

| Поле           | Описание                    |
| -------------- | --------------------------- |
| `id`           | Артикул Wildberries         |
| `name`         | Название товара             |
| `currentPrice` | Текущая цена товара         |
| `inStock`      | Наличие товара              |
| `updatedAt`    | Время последнего обновления |

### `priceHistory`

Хранит историю цен товаров.

| Поле          | Описание                    |
| ------------- | --------------------------- |
| `productId`   | Ссылка на товар             |
| `priceAtTime` | Цена товара в момент записи |
| `recordedAt`  | Время записи                |

Один товар может иметь несколько записей в истории цен.

### `cookiesStorage`

Хранит актуальную cookie-сессию Wildberries, используемую парсером.

## API

### `GET /`

Проверка работоспособности сервиса.

```http
GET /
```

### `GET /parse/:id`

Парсинг товара по артикулу Wildberries.

```http
GET /parse/12345678
```

Пример ответа:

```json
{
  "name": "Product name",
  "price": 1999,
  "inStock": true
}
```

### `POST /set-product/:id`

Добавить товар в список мониторинга.

```http
POST /set-product/12345678
```

### `POST /delete-product/:id`

Удалить товар из списка мониторинга.

```http
POST /delete-product/12345678
```

### `GET /all`

Получить все товары, сохранённые в базе данных.

```http
GET /all
```

### `GET /get/:id`

Получить товар и историю изменения его цены.

```http
GET /get/12345678
```

## Установка

### Требования

* [Bun](https://bun.sh/)
* PostgreSQL
* Chromium или Google Chrome

### 1. Клонирование репозитория

```bash
git clone https://github.com/beep2005/wb-parser-bun.git
cd wb-parser-bun
```

### 2. Установка зависимостей

```bash
bun install
```

### 3. Настройка переменных окружения

Создайте `.env` на основе `.env.example`:

```bash
cp .env.example .env
```

Пример:

```env
PORT=8000

DATABASE_URL=postgresql://user:password@localhost:5432/wbparser

WB_CARD_URL=https://www.wildberries.ru/__internal/u-card/cards/v4/detail

deviceid=your-device-id
```

**Не добавляйте `.env` в Git.**

### 4. Настройка базы данных

Создайте PostgreSQL database и укажите строку подключения в `DATABASE_URL`.

Примените миграции:

```bash
bunx drizzle-kit migrate
```

### 5. Запуск приложения

Режим разработки:

```bash
bun run dev
```

Продакшен:

```bash
bun run start
```

Сервер будет запущен на порту, указанном в `PORT`.

## Обработка ошибок

Парсер обрабатывает несколько типов ошибок:

| Ситуация                          | Поведение                                 |
| --------------------------------- | ----------------------------------------- |
| Товар существует                  | Данные товара обновляются                 |
| Товар отсутствует в наличии       | Обновляется статус наличия                |
| Сессия истекла (`498`)            | Cookies обновляются                       |
| Временная ошибка запроса          | Запрос повторяется                        |
| Некорректный/несуществующий товар | Товар обрабатывается как недействительный |

## Почему Bun?

Проект создан на Bun в качестве эксперимента с быстрым JavaScript/TypeScript runtime и его встроенными возможностями.

Bun предоставляет:

* Быстрый запуск приложений
* Нативное выполнение TypeScript
* Встроенный package manager
* `Bun.WebView` для работы с браузерными сессиями
* Лёгкий runtime для backend-сервисов

В проекте также используется Elysia — лёгкий типобезопасный HTTP-фреймворк, ориентированный на Bun.
